# Motion Pair 标注说明

## 访问方式

请确保你的电脑和标注服务器在同一个内网下，然后用浏览器打开：

```text
http://<annotation-server>:7860
```

如果负责人给了带名字的链接，也可以直接打开：

```text
http://<annotation-server>:7860?annotator=<your_name>
```

页面上方的 `Annotator` 请填写自己的标注员 ID，例如姓名拼音或负责人指定的名字。不要和别人共用同一个 ID。

## 标注目标

每一题会同时播放两个机器人动作视频。你需要判断哪个动作整体更好，然后点击：

- `Left Better`: 左边更好
- `Right Better`: 右边更好
- `Similar`: 两边质量接近，难以区分
- `Cannot compare`: 两边都明显不可用，例如都严重摔倒、完全失控或无法判断

提交后页面会自动加载下一题。

如果刚刚标错，可以点击 `Undo`，或按键盘 `U`。每次只回退自己最近提交的一题，
最多可以连续回退 5 次；回退后页面会重新显示对应题目供你修改。回退只按页面上方的
`Annotator` ID 操作，不会撤销其他标注员的结果。

## 判断优先级

请按下面顺序判断动作好坏。越靠前的标准越重要。

1. **是否完成动作，是否避免摔倒**

   首先选择能够完整完成动作、没有摔倒、没有明显失控的一边。即使另一边看起来局部更自然，只要它摔倒或任务没有完成，通常也应选择完成动作的一边。

2. **抖动是否更小**

   如果两边都完成了动作，优先选择身体、手臂、腿部和根节点抖动更少的一边。明显高频震颤、身体抽动、姿态突然跳变都算扣分。

3. **脚部滑动是否更小**

   如果稳定性接近，优先选择脚底接触地面时滑动更少的一边。站立或支撑脚在地面上明显漂移、打滑、拖动，说明动作质量更差。

4. **行走/移动是否更合理**

   对需要走路或移动的动作，优先选择步态更连贯、重心转移更合理、脚步节奏更自然的一边。原地乱踩、步幅异常、方向明显不对都应扣分。

5. **动作是否更拟人**

   最后比较动作整体是否像人：姿态是否协调，四肢配合是否自然，动作节奏是否符合常识，是否有明显机器人式僵硬或不合理扭曲。

## 常见情况

- 一边完成动作，另一边摔倒：选择完成动作的一边。
- 两边都完成动作，但一边明显抖动：选择抖动小的一边。
- 两边都稳定，但一边脚底明显滑：选择脚滑小的一边。
- 两边差异很小，看不出明显优劣：选择 `Similar`。
- 两边都摔倒、都严重失控，或视频无法判断：选择 `Cannot compare`。

## 注意事项

- 每题只按当前看到的视频判断，不要试图猜测模型名称。
- 标注时保持自己的标准一致，不需要追求和别人完全相同。
- 如果页面长时间显示加载或视频不播放，可以刷新页面；未提交的题目会在超时后自动回到任务池。
- 不要重复使用别人的 annotator id，否则后续统计会混在一起。
